# Security policy

## Supported versions

This repository has no numbered releases. The supported code is the default branch that deploys the hub (`www.bfloore.online`), the resume site (`resume.bfloore.online`), and the reviews site (`reviews.bfloore.online`).

## Reporting a vulnerability

Report security issues privately through GitHub private vulnerability reporting:

https://github.com/BAFfle-d/bflooreonline/security/advisories/new

Do not open a public GitHub issue, pull request, or discussion for a suspected vulnerability, and do not send vulnerability reports to a public email address.

Include what you found, where it is, and enough detail to reproduce it. A maintainer will reply through the private advisory. Please give them a reasonable window to investigate before any public disclosure.

Private vulnerability reporting has to be enabled by a repository admin. Until that switch is on, the link above is still the reporting path to use. It is not a public inbox.
